# GulfSufra — Marina Social Media page

Route: `/services/social-media`

Included: Marina hero, four service highlights, three illustrative sample posts, profile mockup, 3-step process, final CTA, and inquiry modal.

Navigation: shared Header Services dropdown, Services page Learn More, and footer all link to the new route.

Inquiry delivery: uses `/api/inquiry` with `service: "Social Media"`. On Vercel, set `RESEND_API_KEY` and `RESEND_FROM_EMAIL` to enable email delivery. The recipient is currently `yalla@gulfsufri.com`. Demo social engagement shown inside existing mockup images is illustrative, not real results.

Advanced effects and final polish are intentionally deferred.
