# GulfSufra — Universal Header Refinement (October 2026)

This update refines the shared header on all pages. It does not modify Jinni's Restaurant Websites hero, section assets, template cards, inquiry form, or animations.

## What changed
- Slimmed the header to 66px high and replaced the previous heavy grey-green/glossy treatment with rich, deep emerald translucent glass.
- Reduced the bright gold outline to a subtle hairline and soft top reflection.
- Preserved the original logo and tuned its dimensions to avoid stretching.
- Made menu text smaller and more balanced; kept the existing routes and highlighted active page.
- Tightened the Get Started CTA and spacing, with a subtle gold gradient.
- Fixed the Services dropdown hover gap on desktop.
- Improved the mobile menu: Services can be expanded with its chevron, and a Get Started CTA appears in the mobile dropdown.
- Kept a darker, slightly shorter sticky header after scrolling.

## Deploy
Extract the ZIP, deploy the complete folder as a Vite project to Vercel, and test the header at common viewport sizes (desktop, tablet, phone).
