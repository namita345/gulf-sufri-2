# GulfSufra React project

Converted from the supplied static website into a React + Vite project. The original CSS and assets are retained; the existing homepage markup has been migrated to JSX. Four additional pages use clearly marked placeholder copy.

## Run locally
1. Install Node.js (LTS).
2. In this folder run `npm install`.
3. Run `npm run dev`.
4. For production build, run `npm run build`.

## Notes
- The contact form is a front-end demo and does not send submissions until connected to a form service/backend.
- Pricing is marked “Price to be confirmed”; no prices have been invented.
- Review the Home page visually after running locally. React conversion can require small JSX/CSS adjustments; compare against the original before deployment.
