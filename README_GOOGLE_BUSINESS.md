# GulfSufra — Mummo Google Business page

New page: `/services/google-business`

## Included
- Mummo hero with the existing GulfSufra Google mockup imagery
- Four profile-management feature cards
- Interactive profile focus tabs (Details, Photos, Reputation)
- Google Business Profile visual example and explanation
- Three-step service process, FAQs and inquiry modal
- Responsive desktop/tablet/mobile layout
- Header Services dropdown, Services Learn More and footer link to new route
- Inquiry API accepts the `Google Business` service. Email delivery requires `RESEND_API_KEY` and `RESEND_FROM_EMAIL` in Vercel.

All Google listing images are *illustrative demo concepts*; their restaurant name, scores and reviews are not verified client testimonials. Do not present them as factual outcomes. No rankings or reviews are guaranteed.

The shared navigation remains styled exactly as before. No other page design files changed.
